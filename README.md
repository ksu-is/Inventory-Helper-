# Inventory-Helper - Jonathan Scott's IS 3020 project
Project Overview

This project is an inventory tracking web application developed independently for IS 3020. Using Flask, the application will provide a user-friendly interface for monitoring inventory levels, tracking sales data, and predicting future restocking needs.

Planned Features

Inventory Tracking: View and manage products and their current inventory levels.
Sales Data Input: Enter daily, weekly, or monthly sales information.
Restock Predictions: Estimate when products will need to be reordered based on sales trends.
Seasonal Demand: Account for seasonal changes in demand for designated products.
Restock Alerts: Notify users when inventory may run out before a new order arrives.
Reorder Reminders: Set custom dates for product reordering.
Sales Trends: View historical sales data and trends (if time permits).
Spreadsheet Import: Explore options for importing inventory and sales data from spreadsheets.
